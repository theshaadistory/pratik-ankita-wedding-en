Two people, one big day, and a website to tell you all about it.

This repository holds the digital invitation for the wedding of **Pratik and Ankita**. It is a simple static site, built with plain HTML, CSS and JavaScript, and hosted free on GitHub Pages. No app to download, no paper to lose. Open the link, and the celebration is right there.

## What you'll find on the invite

- **Our story:** a short look at how we got here
- **The celebrations:** dates, times and venues for each event
- **Getting there:** location details and directions
- **RSVP:** a quick way to let us know you're coming
- **Little details:** dress ideas, stay suggestions and answers to common questions
